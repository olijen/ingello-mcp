# Ingello MCP

MCP-сервер [Ingello Systems](https://systems.ingello.com) — разработка бизнес-систем на заказ: CRM, ERP, WMS, TMS, SaaS-платформы, маркетплейсы, ИИ-агенты и интеграции.

Позволяет любому ИИ-агенту узнать о компании, задать вопросы по проекту и оформить заявку от имени пользователя. Авторизация не нужна.

## Установка

```json
{
  "mcpServers": {
    "ingello": {
      "command": "npx",
      "args": ["-y", "ingello-mcp"],
      "env": { "INGELLO_AGENT_ID": "your-agent-name" }
    }
  }
}
```

## Инструменты

| Инструмент | Что делает | Лимит |
| --- | --- | --- |
| `ingello_overview` | Услуги, отрасли, кейсы, лимиты | без лимита |
| `ingello_ask` | Вопрос об услугах, подходе, ориентирах бюджета | 5 вопросов на агента |
| `ingello_submit_request` | Заявка на проект от имени пользователя | без лимита |

`ingello_ask` работает асинхронно: сервер сам дожидается ответа (по умолчанию до 5 минут). Когда лимит вопросов исчерпан, инструмент возвращает не отказ, а следующий шаг — оформить заявку, после чего отвечает человек и лимита нет.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `INGELLO_AGENT_ID` | `mcp-client` | Как агент представляется; по нему считается лимит |
| `INGELLO_AGENT_API` | `https://ai.ingello.com` | Базовый адрес API |
| `INGELLO_ANSWER_TIMEOUT_MS` | `300000` | Сколько ждать асинхронный ответ |

## Без MCP

Тот же функционал доступен обычным HTTP: манифест `GET https://ai.ingello.com/agent`, спецификация `GET https://ai.ingello.com/agent/openapi.json`, руководство <https://systems.ingello.com/agents.md>.

## Правила хорошего тона

Представляйтесь в `INGELLO_AGENT_ID`. Не передавайте контакт пользователя без его согласия. Ориентиры цен и сроков предварительные — точная оценка после уточнения задачи.
